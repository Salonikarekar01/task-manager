# Task Manager

**Author:** Saloni Karekar

## Description
A simple task manager web app where users can add tasks, mark them as
complete, and delete them. Built as part of Git & GitHub internship training
to practice issues, branches, and pull requests.

## Features
- Add a new task
- Display all tasks
- Mark a task as complete (strikethrough)
- Delete a task

## Technology Used
- HTML
- CSS
- JavaScript

## How to Run
1. Clone this repository
2. Open `todo.html` in a browser, or serve it locally (e.g. with Live Server)

## What I Learned
Through this exercise I learned how GitHub Issues are used to track
planned work, how a Project board visualizes progress across
Todo/In Progress/Review/Done, and how feature branches keep changes
isolated from main until they're reviewed. I also practiced writing
a Pull Request that links back to an Issue using "Closes #<number>",
so merging automatically closes the Issue and updates its status.
